## Description

Project for a tournament gaming platform. This is the backend for the platform.

## Tech Stack

- NestJS
- Prisma
- MySQL
- TypeScript

## Compile and run the project

- change `.env.example` into `.env` and config it depending on your environnement

```bash
$ npm i
# development
$ npm run start

# watch mode
$ npm run start:dev
```

## Run tests

```bash
# unit tests
$ npm run test
```
